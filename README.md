# Clinical-Decision-Support-System-for-30-Day-Heart-Failure-Readmission
A Clinical Decision Support System for 30-day heart failure readmission risk prediction following discharge. Grounded in the 2022 AHA/ACC/HFSA guidelines, this project utilizes an Explainable AI-powered tool for evidence-based decision-making. It integrates Logistic Regression with an LLM-based RAG for clinical summary generation, Guideline-Directed Medical Therapy (GDMT) optimization, and discharge action planning.
