# Clinical-Decision-Support-System-for-30-Day-Heart-Failure-Readmission
A Clinical Decision Support System for 30-day heart failure readmission risk prediction following discharge. Grounded in the 2022 AHA/ACC/HFSA guidelines, this project utilizes an Explainable AI-powered tool for evidence-based decision-making. It integrates Logistic Regression with an LLM-based RAG for clinical summary generation, Guideline-Directed Medical Therapy (GDMT) optimization, and discharge action planning.  

**🎯 Project Objectives and Overview** 

Heart failure readmission is a major challenge for healthcare systems. The primary objective of this system is to accurately identify high-risk patients at the time of discharge and provide evidence-based clinical recommendations to optimize treatment. This system allows physicians to review the patient's physiological profile (including vital signs, laboratory tests, and medications) and, by receiving early warnings, make more accurate decisions regarding discharge or referral to specialized care programs.

**🩺 Based on Leading Medical and AI Standards**

To ensure the credibility and reliability of this system, its development is based on two key standards:

*2022 AHA/ACC/HFSA Clinical Guidelines:*

All extracted features (including GDMT medications, biomarkers, and vital signs) as well as reports generated by the system's generative AI fully comply with the American Heart Association's heart failure management guidelines.

*Transparency with TRIPOD+AI Standards:*

To ensure transparency in the risk estimation process, cross-validation, and reporting of model performance metrics (such as sensitivity, specificity, and unbiased positive predictive value), the TRIPOD+AI standard reporting framework for clinical prediction models has been followed.


**⚠️ Proof of Concept Statement and Data Limitations**

This project was developed using the demo version of the MIMIC-IV database. Due to the use of the demo version, the number of patients and training samples is limited.

This repository currently serves as a Proof of Concept to demonstrate the architecture, clinical data processing pipeline, and its integration with the user interface and LLMs. For operational implementation and deployment of this system in a real clinical environment, retraining the model on much larger datasets is required to recognise patterns with high accuracy.

🛠️ Pipeline and Project Modules The project is modularly designed and includes the following sections: Cohort Extraction: Identifying heart failure patients and creating the 30-day readmission label (merge.py).
Clinical Feature Engineering: Extracting ICU vital values (LVEF, urine output, blood pressure changes) and lab tests from the MIMIC database (making_feature_matrix_and_output_variable.py).
Statistical Feature Selection: Using KNN Imputation and P-Value-based Backward Elimination to select the most significant variables (feature_selection.py).
Comprehensive Training and Evaluation: Setting the clinical decision threshold (to achieve high sensitivity > 80%) and evaluating the model with 5-Fold Cross Validation (Implement_ML.py and 5_Fold_CV_ML.py).
User Interface and RAG: Integrating the trained model, XAI, and LangChain within the Streamlit environment (app.py).
