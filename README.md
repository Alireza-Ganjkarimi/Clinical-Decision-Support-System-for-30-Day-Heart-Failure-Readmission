# Clinical-Decision-Support-System-for-30-Day-Heart-Failure-Readmission
A Clinical Decision Support System for 30-Day Heart Failure Readmission Risk Prediction. Built on 2022 AHA/ACC/HFSA guidelines, this project integrates Logistic Regression with LLM-based RAG for Clinical Summary, GDMT Optimization, and Discharge Action Plans. An Explainable AI-powered tool for evidence-based decision making.
