# Clinical-Decision-Support-System-for-30-Day-Heart-Failure-Readmission
A Clinical Decision Support System for 30-day heart failure readmission risk prediction following discharge. Grounded in the [2022 AHA/ACC/HFSA Heart Failure Management guidelines](https://www.ahajournals.org/doi/10.1161/CIR.0000000000001063), this project utilizes an Explainable AI-powered tool for evidence-based decision-making. It integrates Logistic Regression with an LLM-based RAG for 30-day heart failure readmission risk prediction, clinical summary generation, Guideline-Directed Medical Therapy (GDMT) optimization, and discharge action planning.  

## 🎯 Project Objectives and Overview

Heart failure readmission is a major challenge for healthcare systems. The primary objective of this system is to accurately identify high-risk patients at the time of discharge and provide evidence-based clinical recommendations to optimize treatment. This system allows physicians to review the patient's physiological profile (including vital signs, laboratory tests, and medications) and, by receiving early warnings and utilising guideline based large language model(LLM), make more accurate decisions regarding discharge or referral to specialized care programs.

## 🩺 Based on Leading Medical and AI Standards

To ensure the credibility and reliability of this system, its development is based on two key standards:

**2022 AHA/ACC/HFSA Clinical Guidelines:**

All extracted features as well as reports generated by the system's generative AI fully comply with the [American Heart Association's heart failure management guidelines](https://www.ahajournals.org/doi/10.1161/CIR.0000000000001063). To ensure clinical relevance, the following guideline-directed features were specifically extracted from the MIMIC-IV database:

•	**Biomarkers:** NT-proBNP, Creatinine, Blood Urea Nitrogen (BUN), Sodium, Potassium, and Hemoglobin (tracking initial, final, and change values to monitor patient trajectory).

•	**Hemodynamics & Vitals:** Heart Rate (minimum, maximum, mean, and last recorded), Blood Pressure (Systolic and Diastolic trends), and Left Ventricular Ejection Fraction (LVEF).

•	**Guideline-Directed Medical Therapy (GDMT) Medications:** Beta-Blockers, ACEi/ARB/ARNi, Mineralocorticoid Receptor Antagonists (MRAs), and Loop Diuretics.

•	**Comorbidities:** Atrial Fibrillation, Diabetes Mellitus, Hypertension, and Chronic Kidney Disease (CKD).

•	**Volume Status:** Total Urine Output (as a proxy for fluid congestion and diuretic response).



**Transparency with TRIPOD+AI Standards:**

To ensure transparency in the risk estimation process, cross-validation, and reporting of model performance metrics (such as sensitivity, specificity, and unbiased positive predictive value), the [TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378) standard reporting framework for clinical prediction models has been followed.


## ⚠️ Proof of Concept Statement and Data Limitations

This project was developed using the [demo version of the MIMIC-IV database](https://www.kaggle.com/datasets/montassarba/mimic-iv-clinical-database-demo-2-2/code). Due to the use of the demo version, the number of patients and training samples is limited.

This repository currently serves as a Proof of Concept to demonstrate the architecture, clinical data processing pipeline, and its integration with the user interface and LLMs. For operational implementation and deployment of this system in a real clinical environment, retraining the model on much larger datasets is required to recognise patterns with high accuracy.

## 📊 Key Results and System User Interface

The system's design aims to present complex statistical calculations through an intuitive, simple, and understandable user interface for healthcare staff.

**1.	Interactive Dashboard and AI Analysis**

The interactive system dashboard allows for searching and loading data extracted from patients' health records. Using 5 selected significant features and a logistic regression model, the system calculates the risk of readmission.

Clinical Note on Risk Interpretation: It is crucial to interpret the predicted risk relative to the baseline prevalence of heart failure readmission (approximately 18.4% in the US). For instance, a predicted probability of 40% is not a "moderate" risk; it represents more than double the normal baseline risk (2x Relative Risk), triggering a critical high-risk alert. Accordingly, the clinical decision threshold (e.g., ~22.4%) is dynamically set to guarantee 80% sensitivity, flagging patients as soon as their risk significantly deviates upward from the baseline.

At approximately 20.7%, it perfectly mirrors the actual readmission prevalence in the dataset (24.5%) and baseline prevalence in real world(18.4% in US). This alignment confirms the model is unbiased and mathematically grounded in the true prevalence rate. The value $f(x)$ is the final individualized risk calculated after each specific clinical feature pushes the probability up or down from this baseline. By intelligently searching authoritative and up-to-date medical guidelines (2022 AHA/ACC/HFSA heart failure guidelines), the AI retrieves the most relevant documents and generates a structured clinical report based on them. This report includes a summary of the clinical status, an evaluation of guideline-directed medical therapy (GDMT) optimization, and a patient discharge and follow-up plan—an approach that makes the system's recommendations are fully documented and free from AI hallucination errors. **2.	Model Reliability and Calibration**

In clinical models, discrimination power (AUROC) is not the only important factor; precise calibration (matching predicted probability with the actual risk rate) is vital. The chart below shows the model's calibration status along with a 95% confidence interval (calculated using the bootstrapping method).

Note on Model Calibration: The curve demonstrates excellent agreement between predicted probabilities and actual risk, particularly in the lower and moderate probability ranges. Due to the stochastic nature of readmission and unrecorded post-discharge variables (such as medication adherence or sudden infections), true readmission rates rarely reach 80% or 90% even in the sickest cohorts. A well-calibrated model reflects this reality; if the highest-risk group has a 50% actual readmission rate, the model correctly outputs 50% rather than generating overconfident, exaggerated probabilities. Again, it is important to reiterate that a 50% predicted risk for an event with an overall baseline prevalence of approximately 18.4% is by no means a low risk; rather, it is considered exceptionally high.

## 🛠️ Pipeline and Project Modules
The project is modularly designed and includes the following sections: 

**Cohort Extraction:** Identifying heart failure patients and creating the 30-day readmission label (`merge.py`).

**Clinical Feature Engineering:** Extracting vital values, comorbidity of disease, prescribed drug, and lab tests from the MIMIC database (`making_feature_matrix.py`).

**Statistical Feature Selection:** Using KNN Imputation and P-Value-based Backward Elimination to impute the missing values and select the most significant variables, respectively (`feature_selection.py`).

**Training and Evaluation:** Setting the clinical decision threshold and evaluating the model with 5-Fold Subject-wise Cross Validation (`Implement_ML.py and 5_Fold_CV_ML.py`).

**User Interface and RAG:** Integrating the trained model, XAI, and LLM within the Streamlit environment (app.py).
